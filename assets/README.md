# HUMAN // LOKESH assets

Original artwork is generated by `scripts/build_brand.py` using shared palettes and geometry.
`brand/` contains identity, toolkit, lab, closing, and connection assets; `project-cards/` contains the showcase.
Hero, immutable role panel, toolkit, project cards, learning lab, and closing graphics have theme/viewport variants.
All displayed images are hosted here and use system-font fallbacks. No JavaScript or font service is required.
Explicit static variants are selected by the README for reduced motion; they contain no animation instructions.

Vendored technology logos come from
<https://github.com/devicons/devicon/tree/v2.16.0/icons>.
Their license is retained in `icons/LICENSE`; technology names and marks belong to their respective owners.
LangGraph and FAISS use original schematic marks with clear labels rather than vendor logos.

`live/` holds actual public GitHub data and generated visualizations, updated by GitHub Actions.
The primary-project-language chart excludes this profile and forks. Weekly bars use actual calendar counts.
The contribution snakes use <https://github.com/Platane/snk> at
`d8f6715049803e982ee5ff501b6b9b7d5deeb09b` (v3.5.0), and retain its embedded source attribution.
