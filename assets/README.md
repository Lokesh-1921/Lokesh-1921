# Profile assets

Original brand artwork is generated by `scripts/build_brand.py`.
The assets are self-contained SVGs with system-font fallbacks; all displayed images are hosted here.
Edit the script, then rerun it to keep theme and viewport variants consistent.

Vendored technology logos come from
<https://github.com/devicons/devicon/tree/v2.16.0/icons>.
Their license is retained in `icons/LICENSE`; technology names and marks belong to their respective owners.
LangGraph and FAISS use original letter marks rather than vendor logos.

`live/` holds actual public GitHub data and generated visualizations, updated by GitHub Actions.
The contribution snakes use <https://github.com/Platane/snk> at
`d8f6715049803e982ee5ff501b6b9b7d5deeb09b` (v3.5.0), and retain its embedded source attribution.
